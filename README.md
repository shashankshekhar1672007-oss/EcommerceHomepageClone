# E-Commerce Homepage UI Clone

A responsive frontend landing page clone of a modern e-commerce homepage layout, built from scratch using pure **HTML5** and **CSS3**.

Created as a beginner project to practice web design, navigation layouts, CSS positioning, and flexbox.

## 🚀 Live Demo & Deployment

This project contains pure static HTML & CSS, making it 1-click deployable:

### Option 1: GitHub Pages
1. Go to your repository on GitHub.
2. Navigate to **Settings** > **Pages**.
3. Under **Build and deployment** > **Branch**, select `main` (root) and click **Save**.
4. Your site will be live at `https://<username>.github.io/<repository-name>/`.

### Option 2: Run Locally
Simply clone this repository and open `index.html` in any web browser:
```bash
git clone https://github.com/<your-username>/<repo-name>.git
cd <repo-name>
open index.html
```
